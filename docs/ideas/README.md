# Ideas backlog

These are deferred ideas, not implemented features.

1. Public SaaS: tenant creation/isolation audit, per-workspace management, billing, provider approval and onboarding review, usage limits, retention and export/deletion policies.
2. Stepline CRM connector built on the generic REST/webhook contract.
3. OIDC/SSO, MFA, password-reset workflow and account recovery.
4. Conversation assignment, tags, notes, per-user unread state and search across historical messages.
5. S3-compatible storage, malware scanning, media previews and audio format conversion/recording.
6. Worker/session partitioning, horizontally scalable ownership, observability metrics and alerting.
7. Supervised failed-webhook replay, dead-letter inspection and controlled retention cleanup.
8. More provider-specific message types, supported group APIs when eligibility is verified, edit/receipt coverage improvements, richer template UI.
9. Encryption-key rotation migration, managed key vault and backup-retention tooling.
10. Russian/Kazakh localization after the internal workflow settles.

Evaluate risk/consent before considering automated campaigns. Unofficial-provider ban evasion, scraping, account rotation or stealth are not roadmap goals.
