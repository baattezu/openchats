# ADR 006: Single-page inbox from the user’s wireframe

Status: accepted · 2026-10-13

Decision: profile and API/workspace controls across the top left, provider account rows beneath, message feed below, selected conversation on the right. Account setup, roles, keys, webhooks and activity use dialogs. Collapse to a single full-width conversation on mobile. Utilitarian light UI, self-hosted Inter/Space Grotesk fonts, shared design tokens, native dialog focus handling and visible loading/error/empty states. Hallmark guides restraint/accessibility; the supplied wireframe owns the structure.

No fake plan label, statistics, messages or success states. Account identity and health replace decorative toggles. Feed rows show sender, preview, time and unread count. Admin controls are absent for members, with matching API enforcement.

API responses determine capabilities. Sending attachments and voice-note files is supported; a browser audio recorder is deferred. The UI selects approved text-only WhatsApp templates and asks for positional body variables. Templates with headers/buttons and advanced components remain available through the REST API.

Consequences: a focused internal workflow without separate dashboards or billing screens. English UI copy is the v1 default; localization and personal unread states are future work.
